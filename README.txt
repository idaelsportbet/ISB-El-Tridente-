ISB | EL TRIDENTE — PRIMERA VERSIÓN

Archivos:
- index.html
- styles.css
- script.js
- assets/hero.jpeg
- vercel.json

Esta primera versión incluye:
- Portada responsive para iPhone y computadora.
- Menú: Inicio, Cómo funciona, Resultados, Soporte, Contacto.
- Botones de Iniciar sesión y Registrarse.
- Formularios visuales de login/registro.
- Paquetes y precios ocultos de la portada pública.
- WhatsApp y correo de soporte.

IMPORTANTE:
El login/registro de esta versión es una DEMO visual. El siguiente paso es conectar Supabase para cuentas reales, base de datos, membresías y acceso privado.

SUBIR A VERCEL DESDE IPHONE:
1. Descomprime el ZIP en Archivos.
2. En Vercel, dentro de “Implementa tu primer proyecto”, toca “carpeta”.
3. Selecciona la carpeta isb_el_tridente_site completa.
4. Continúa con Deploy/Implementar.
